01ML-стек в платформе · обновления

ML-стек обновляется вместе с кластером

Совместимость драйверов NVIDIA с ядром, containerd, Kubernetes и Kubeflow проверяет команда Штурвала

Драйверы, плагины, Kubeflow и MLflow работают как сервисы кластера. Внутренний проект «починить GPU после апдейта» больше не нужен.

  • По кнопке или по расписаниюОбновление кластера включает GPU- и ML-стек
  • Изолированно по кластерамСначала тестовый кластер, потом прод. Один кластер не тянет за собой остальные
  • В закрытом контуреОбновление идёт из вашего зеркала, без выхода в интернет
  • Отдельные кластеры для экспериментов и продаВторой кластер создаётся из того же Штурвала и обслуживается из одной точки

02Экономия · GPU по запросу

  
Гибко управляйте своими картами

  

    
Целая карта
Обучение на A100 из GPU-группы узлов


# Обучение на A100 из GPU-группы
spec:
  nodeSelector:
    nvidia.com/gpu.product: NVIDIA-A100-SXM4-80GB
  tolerations:
    - key: nvidia.com/gpu
      operator: Exists
  containers:
    - name: train
      image: pytorch/pytorch
      resources:
        limits:
          nvidia.com/gpu: 1

    
Несколько карт
Дообучение LLM на четырёх H100 одного узла


# Дообучение LLM на четырёх H100 одного узла
spec:
  nodeSelector:
    nvidia.com/gpu.product: NVIDIA-H100-80GB-HBM3
  containers:
    - name: train
      image: pytorch/pytorch
      resources:
        limits:
          nvidia.com/gpu: 4
# Для обучения на нескольких узлах:
# PyTorchJob в Training Operator

    
MIG
Ноутбук на седьмой части карты


# Ноутбук на седьмой части карты
spec:
  containers:
    - name: notebook
      image: jupyter/scipy-notebook
      resources:
        limits:
          nvidia.com/mig-1g.10gb: 1
# Остальные слайсы этой GPU
# доступны другим задачам

    
Time-slice
Ноутбук на карте, которую делят по времени


# Ноутбук на карте, которую делят по времени
spec:
  nodeSelector:
    nvidia.com/gpu.sharing-strategy: time-slicing
  containers:
    - name: notebook
      image: jupyter/scipy-notebook
      resources:
        limits:
          nvidia.com/gpu: 1
# Одна физическая карта обслуживает
# несколько подов по очереди
